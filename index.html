📂 Accessible Accordion

Operable with Enter or Space. Uses aria-expanded and aria-controls.

Native elements like <button> and <input> have built-in keyboard support, focus management, and screen reader roles out of the box (First Rule of ARIA).
Roving tabindex keeps only the active item at tabindex="0" while siblings are at tabindex="-1". The arrow keys shift focus and adjust tabindex dynamically.
Any keyboard operable user interface must have an operating mode where the keyboard focus indicator is visible. Never remove outline without an accessible replacement!
